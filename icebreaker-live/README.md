# 認識你，也讓你認識我｜多人同步卡牌網站 V1.3

客服中心新人培訓用即時互動網站。支援講師建立活動時自訂小組數量、人數上限、參與方式和新人／管理職名額，保留三階段 30 張卡牌、每組獨立抽卡、共享倒數計時器、講師成員管理及活動紀錄匯出。

## 本次更新：可自由設定活動配置

講師於首頁「我是講師」建立活動前設定：

- **小組數量：** 1–12 組。
- **各組參與方式：** 線上或現場；不混組。
- **各組人數上限：** 1–12 人，單場總名額最多 100 人。
- **各組成員身分名額：** 新人與管理職人數分別指定，兩者之和必須等於該組上限；允許其中一種身分為 0 人。
- **快捷範例：** 「3 組 ×（2 新人＋1 管理職）」（本次 6 位新人＋3 位管理職，全部現場），以及「5 組混成培訓」（14 位線上、4 位現場，全部新人）。

新人／管理職加入時選擇參與方式和身分，伺服器只分配到對應名額未滿的小組。預先保留的講師新增成員亦占用名額，並使用個人加入碼認領。成員調組僅允許相同參與方式且目標組該身分仍有名額。講師可隨時移除成員。

**重要：** 分組設定是在「建立活動」時決定，已建立的活動不能在中途修改組數、各組容量或身分配額。既有 V1.2 活動不會被自動重新分組；新配置請另建活動。已存在的舊活動仍可讀取，預設舊成員均視為新人，舊組別配置維持不變。

## 部署到現有 Render 服務

1. 解壓縮 ZIP，將其中 `icebreaker-live/` 資料夾內容以相同路徑更新到原本 GitHub 專案（**不要上傳** `node_modules/`、`data/rooms.json`）。
2. 提交 GitHub Commit，等待 Render 自動部署或選 **Manual Deploy → Deploy latest commit**。
3. 確認 Render 的 Root Directory 為 `icebreaker-live`，Build Command 為 `npm install --omit=dev`，Start Command 為 `npm start`，Health Check 為 `/health`。
4. 瀏覽原 Render 網站，講師點選三組範例，確認顯示三組各 3 人、每組新人 2 人與管理職 1 人，然後「建立新活動」。
5. 將網站生成的新人加入連結傳送給參與者；加入時選擇「現場參與」和實際身分。

**費用／儲存：** `render.yaml` 採 Render Starter 付費服務與持久磁碟，正式費用以平台為準；單一 Web Service 實例。不要在多個服務實例間共用本機 JSON 資料庫。

## 操作方式

- 講師建立活動後可切換三階段、替任一小組抽卡、控制計時器、管理成員與匯出 JSON。
- 參與者只能抽取自己組別卡牌；同組抽卡會即時同步。
- 講師可新增預留成員（選擇姓名、組別、身分）、複製個人加入碼、移動或移除現有成員。
- 若成員以個人加入碼認領名額，加入時參與方式與身分需與預留設定一致。
- 刪除成員會撤銷該名額的原登入憑證；僅「離開此裝置」不會釋出名額。
- 本機啟動：安裝 Node.js 20+，執行 `npm install` 和 `npm start`，瀏覽 `http://localhost:3000`。

## 正式使用前驗收

- 依本次配置建立 3 組，各 3 人，每組 2 名新人＋1 名管理職。
- 在至少兩部裝置加入相同活動，確認新人／管理職自動分配正確。
- 測試該身分名額額滿不能再加入，且現場不能加入線上組。
- 測試講師預留成員、認領加入碼、移除與跨組移動的限制。
- 測試抽卡、階段、計時器與進度同步，刷新頁面後確認紀錄仍在。

## 安全與限制

- 這是輕量級培訓活動網站，沒有企業 SSO；**成員身分由加入者自行選擇**，不具實名身分驗證。若需防止代填身分，請由講師預留所有名額並分發專屬加入碼。
- 講師私密 token 保存在瀏覽器 localStorage，請勿分享講師登入裝置或 token。活動代碼應只提供活動參與者。
- 姓名／暱稱、名額、抽卡紀錄與登入 token 儲存在伺服器持久磁碟；請勿輸入客戶或其他敏感個資，正式企業使用需先完成資安審查。
- 目前未提供「活動建立後」調整容量／身分名額的功能；成員新增／移除／調組仍可即時操作，且受建置時設定上限約束。
