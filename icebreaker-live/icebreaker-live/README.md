# 認識你，也讓你認識我｜多人同步卡牌網站

適合 18 位客服新人（線上 14 位、現場 4 位），固定 5 組（線上第 1–4 組：4、4、3、3 人；現場第 5 組：4 人）的 60 分鐘溝通破冰活動。包含三階段 30 張題目、五組獨立不重複抽卡、講師跨組管理、全員同步倒數、進度保存、匯出活動紀錄。

## 啟動方式（本機驗證）

請先安裝 Node.js 20 以上版本。

```bash
npm install
npm start
```

開啟 `http://localhost:3000`。如需讓同一 Wi-Fi 的手機連線，使用電腦的區域網路 IP（如 `http://192.168.1.10:3000`），並確保防火牆允許連入。正式活動建議使用 HTTPS 網站。

## 線上部署（Render）

1. 將整個專案上傳到自己的 GitHub 儲存庫（請勿包含 `node_modules` 或 `data/rooms.json`）。
2. 登入 [Render](https://dashboard.render.com/)，選擇 **New → Blueprint**，連結儲存庫。
3. Render 會讀取 `render.yaml`，建立一個 Node Web Service 和 1 GB 持久磁碟。確認服務設定及費用後部署。
4. 部署完成後，取得 Render 提供的 `https://...onrender.com` 公開網址，使用手機開啟。
5. 講師點「建立新活動」，複製「新人加入連結」傳給 18 位新人。新人輸入姓名後會自動依序分到尚有空位的小組（依小組上限（4／4／3／3／4 人））。
6. 所有裝置會即時看到相同的抽卡進度、目前階段、倒數；講師可檢視所有五組。

**費用提醒：** `render.yaml` 使用 `starter` 付費方案與持久磁碟，避免服務重新啟動後遺失活動資料。實際費率以 Render 結帳畫面為準。若改用免費或無磁碟配置，服務重新部署／重啟時可能遺失所有活動紀錄，不建議用於正式課程。這份部署設定只支援單一服務實例，請勿設定多實例橫向擴充。

## 操作與權限

- **講師：** 建立活動後會取得高強度私密的講師 token，存在該瀏覽器 localStorage；只有講師能切換階段、設定/啟動/重設倒數、檢視或操作任意小組、重置活動和匯出紀錄。
- **新人：** 以加入連結或活動代碼進入，最多 18 人，加入時選擇線上或現場，伺服器依對應組別自動分配；同組所有人共用抽卡紀錄、不能替別組抽卡。
- **再次進入：** 同一瀏覽器會保留身份 token，斷線後自動重連；若清除瀏覽器資料或更換裝置，需重新加入，原名額不會自動釋出。正式活動請使用同一裝置和瀏覽器。
- **資料：** 持久化儲存活動代碼、講師 token、新人姓名／暱稱、組別、抽卡紀錄及計時狀態，不會儲存任何音訊或對話內容。請避免使用完整員工姓名、電話或顧客個資。若須符合企業資安／個資政策，請先完成內部審查。
- **隱私：** 加入連結是知曉代碼即可進入，並非企業 SSO。若希望只讓指定人員加入，需要另行加入組織登入和授權機制。
- **權限：** 講師連結 / 瀏覽器 token 應妥善保管；分享給新人時只能分享「複製新人加入連結」，不應分享瀏覽器的儲存資料。

## 驗證同步功能

1. 使用一個一般瀏覽器視窗建立活動。
2. 使用其他視窗或手機開啟新人連結，輸入不同暱稱。
3. 觀察講師端的各組人數即時變化。
4. 新人抽卡，確認講師及同組其他人畫面同步變更。
5. 講師切換階段並啟動倒數，所有裝置同步更新；跨裝置時間會依各裝置時鐘有輕微差異。
6. 重新整理網頁確認進度保留，講師可匯出紀錄 JSON。

## 技術架構

Node.js + Express + Socket.IO；用原生 HTML/CSS/JS 提供手機與桌面雙版型；伺服器對所有抽卡及操作做權限和人數限制；活動資料採原子寫入 JSON 存放在持久磁碟。適合單場、小規模固定分組工作坊；不是大規模企業 LMS 平台。必要時可遷移 PostgreSQL 並加入 SSO。

## 2026-11-02 混成培訓分組更新

- 第 1–4 組僅限線上：4、4、3、3 人；第 5 組僅限現場：4 人。
- 新人加入時必須選擇參與方式。分組邏輯由伺服器控制，不能自行跳到另一種組別。
- **更新版本後請建立新活動**，已存在的舊活動與舊成員不會自動重新分組。
- 若 GitHub 儲存庫的程式位於 `icebreaker-live/` 子目錄，Render Web Service 的 Root Directory 應設定為 `icebreaker-live`；本版 `render.yaml` 已新增對應的 `rootDir`。
- 三人組沿用相同的發言時長，提早完成後安排延伸提問及回饋。


## V1.2 講師小組成員管理

- 講師可在「小組成員管理」輸入姓名並選定組別新增預留名額；名額會占用該組容量，講師畫面顯示專屬加入碼。
- 新人使用活動連結，選擇正確參與方式，輸入講師提供的專屬加入碼與姓名即可領取預留名額。一般新人無須填入加入碼，依原規則自動入組。
- 講師可移除成員，移除後該成員登入資格失效，釋出名額；也可在同一參與方式的小組之間調組。
- 保持 1–4 組線上、5 組現場，容量依序 4、4、3、3、4；不允許線上現場混組。
- 網站更新後已存在的活動資料仍可讀取；為避免不同版位混亂，正式活動前請測試。
- 使用公開活動連結及個人加入碼並不構成企業級身份驗證，請勿存放顧客個資。
